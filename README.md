# AI Career Guidance and Internship Finder

A beginner-friendly full-stack college project built with HTML, CSS, Vanilla JavaScript, Node.js, Express.js, and Supabase PostgreSQL.

## 1. What is included?

- Responsive landing page and student career profile form.
- Rule-based career recommendations for AI/Data, Web Development, Cybersecurity, Design, and Business.
- Internship cards with search and domain/pay filters.
- Save/unsave demo internships (saved locally in the browser).
- Express server, health endpoint, and Supabase-backed internship list/create API.
- SQL schema for internships, student profiles, and saved internships.
- Environment variable template and Git ignore rules.

## 2. Important MVP limitations

This starter project is **partially database-connected**:
- The internship API reads and creates rows in Supabase after setup.
- The landing page currently displays clearly labelled sample internships from `frontend/app.js`; it does not yet load the API.
- Career suggestions are rule-based, not generated by a trained AI model or external AI service.
- Login/register dialogs are placeholders. Real authentication, secure student sessions, profile persistence, and server-enforced admin roles are **not implemented** in this starter version. Do not enter real passwords.
- Demo saved internships use browser `localStorage`, not the database.
- SQL creates student-profile and saved-internship tables, but the associated protected endpoints are not yet implemented.

These limitations are stated clearly so the demo does not pretend unfinished features are complete.

## 3. Requirements

Install:
- Node.js LTS (includes npm)
- Visual Studio Code
- A free Supabase account/project
- Git (optional initially, required for GitHub workflow)

## 4. Setup in VS Code

1. Extract the ZIP file.
2. Open the extracted `ai-career-guidance-and-internship-finder` folder in VS Code.
3. Open a terminal in VS Code: **Terminal → New Terminal**.
4. Move into the backend directory:

   ```bash
   cd backend
   npm install
   ```

5. Copy `.env.example` to a new file named `.env` inside `backend/`.
6. Open `backend/.env` and add your Supabase project URL and **server-only service-role key**. Do not commit `.env` or share this key.
7. In Supabase, open **SQL Editor**, paste the contents of `database/schema.sql`, and run it. You may need to navigate to the root folder from the terminal/editor to open this file.
8. In the terminal (still inside `backend/`), start the server:

   ```bash
   npm run dev
   ```

9. Open `http://localhost:3000` in your browser. The API health check is at `http://localhost:3000/api/health`.

If you have not configured Supabase yet, the website UI still opens; database API calls will report that the database is not configured.

## 5. Supabase environment variables

Create `backend/.env` from `backend/.env.example`:

```env
PORT=3000
SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
SUPABASE_SERVICE_ROLE_KEY=YOUR_SERVER_ONLY_SERVICE_ROLE_KEY
NODE_ENV=development
```

Find the project URL and API keys in your Supabase project settings. Keep the service-role key on the server only. Never put it in `frontend/app.js`, HTML, or a public GitHub repository. Because this starter server uses the service-role key, it bypasses Row Level Security; only run it locally while developing, and do not deploy it publicly until proper authentication, authorization, rate limiting, and safe admin access are implemented.

## 6. API endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| GET | `/api/health` | Server status and database-configured flag |
| GET | `/api/internships` | List internships; optional `?domain=AI%20%26%20Data`, `?pay_type=Paid`, or `?search=AI` |
| POST | `/api/internships` | Create an internship record after basic validation |

Example POST body:

```json
{
  "title": "Frontend Intern",
  "company": "Example Company",
  "domain": "Web Development",
  "description": "Work on a practice website with a mentor.",
  "eligibility": "Beginner students",
  "skills": ["HTML", "CSS", "JavaScript"],
  "pay_type": "Paid",
  "work_mode": "Remote",
  "duration": "6 weeks",
  "application_url": "https://example.com/internships"
}
```

The POST endpoint is for local project demonstration only. It has no authentication or admin authorization yet. Do not expose it publicly.

## 10. Troubleshooting

- **`npm` is not recognized:** Install Node.js LTS and restart VS Code.
- **Port is already in use:** Change `PORT=3001` in `backend/.env` and open `http://localhost:3001`.
- **Database not configured:** Check `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` in `backend/.env`.
- **Table not found:** Run `database/schema.sql` in the correct Supabase project.
- **Do not commit secrets:** Confirm `backend/.env` is ignored by Git.
